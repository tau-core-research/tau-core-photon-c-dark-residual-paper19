# Data Notice

This repository contains only synthetic toy data and compact derived artifacts
generated by the repository scripts from the packaged
`Tau_Core_Photon_C_DarkResidual_Package`, including:

- `scripts/run_tcdr_toys.py`;
- `scripts/run_tcdr_robustness.py`;
- `scripts/run_tcdr_blind_challenge.py`;
- `scripts/run_tcdr_realistic_mock_challenge.py`.

The repository also contains a small TCDR-v4 real-data source manifest generated
by `scripts/build_tcdr_v4_real_data_manifest.py`. The manifest lists external
public data sources and their allowed protocol roles; it does not include the
external survey data themselves.

The optional `scripts/download_tcdr_v4_sparc_endpoint.py` script downloads
compact SPARC endpoint/baseline files into `data/external/`, which is ignored
by git. Those downloaded files are local preflight inputs and are not part of
the repository release.

The committed SPARC source-freeze queue is derived from SPARC sample metadata
and intentionally excludes `Vflat` and rotation-curve endpoint values. It is a
candidate-review ledger for future external morphology lookup, not an endpoint
analysis.

The committed P0 S4G lookup artifact contains compact source-side morphology
fields for matched P0 candidates only. It is derived from the public IRSA TAP
`s4gcat` table and remains a source-freeze aid, not a rotation-curve endpoint
analysis.

No real galaxy, lensing, rotation-curve, cosmological, or survey catalogue data
are included. The numerical results are methodology checks, not observational
evidence.
