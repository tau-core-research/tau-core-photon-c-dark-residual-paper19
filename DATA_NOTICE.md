# Data Notice

This repository contains only synthetic toy data and compact derived artifacts
generated by the repository scripts from the packaged
`Tau_Core_Photon_C_DarkResidual_Package`, including:

- `scripts/run_tcdr_toys.py`;
- `scripts/run_tcdr_robustness.py`;
- `scripts/run_tcdr_blind_challenge.py`;
- `scripts/run_tcdr_realistic_mock_challenge.py`.

The repository also contains a small TCDR-v4 real-data source manifest generated
by `scripts/build_tcdr_v4_real_data_manifest.py`. The manifest lists external
public data sources and their allowed protocol roles; it does not include the
external survey data themselves.

The optional `scripts/download_tcdr_v4_sparc_endpoint.py` script downloads
compact SPARC endpoint/baseline files into `data/external/`, which is ignored
by git. Those downloaded files are local preflight inputs and are not part of
the repository release.

The committed SPARC source-freeze queue is derived from SPARC sample metadata
and intentionally excludes `Vflat` and rotation-curve endpoint values. It is a
candidate-review ledger for future external morphology lookup, not an endpoint
analysis.

The committed P0 S4G lookup artifact contains compact source-side morphology
fields for matched P0 candidates only. It is derived from the public IRSA TAP
`s4gcat` table and remains a source-freeze aid, not a rotation-curve endpoint
analysis.

The committed P0 S4G coordinate-lookup artifact uses SIMBAD name resolution
and S4G coordinates to resolve name-alias cases. It is still a source-side
morphology-availability artifact and does not inspect rotation endpoints.

The committed P0 SIMBAD fallback artifact records catalogue identity and
morphological-type fields for non-S4G P0 objects. It is a weaker fallback
source ledger, not a homogeneous morphology catalogue and not endpoint
evidence.

The committed P0 source-tier manifest combines S4G and SIMBAD source ledgers
into a freeze-ready source-quality hierarchy. The tiers describe source
availability only and must not be read as endpoint performance classes.

The committed P0 source-family freeze maps source-side morphology tiers to
candidate readout families. These family labels are allowed pre-endpoint
hypotheses only; they are not fit results and do not use rotation residuals.

The committed P0 pilot holdout manifest is derived only from the committed
source-family freeze artifact. It selects a small, endpoint-blind,
family-balanced homogeneous-S4G pilot subset for later scoring work. It is not
a fit table, does not inspect rotation endpoints, and does not claim that the
selected family will improve any galaxy.

The pilot split is calibration aware. It leaves train support in each selected
homogeneous family and the optional local scoring script blocks families with
fewer than two train galaxies from acting as calibrated matched or wrong-family
controls. This prevents a one-object family amplitude from being promoted into
an endpoint result.

The committed P0 holdout endpoint-readiness manifest records only availability
and coarse count/radial metadata for the frozen holdout objects. The actual
SPARC endpoint curve packet is written locally under `data/external/` and is
not committed. The readiness manifest is not an endpoint score, baseline
comparison, or observational claim.

It records that the present family labels are source proxies: barred and ring
families require structural decomposition, exponential disks have only partial
disk/H I proxy coordinates, diffuse late disks need more train support, and
identity-only cases are not kernel-freeze ready. This audit may guide future
source acquisition but must not be read as endpoint scoring.

The projection sign/load derivation closes only the strict observer-projection
subcase. From `v_los = v_c sin i`, the inclination profile implies
`v_proj^2/v_carrier^2 = (sin i_ref/sin i(R))^2` when the carrier is referenced
to the inner orientation. For NGC2841 this gives an outer factor of about
0.878, or a maximum source-side projection attenuation of about 0.122. This is
a negative multiplicative projection effect, not an added dark-residual load.
The positive outer-capacity branch remains blocked until an independent
velocity-squared load source is frozen.
