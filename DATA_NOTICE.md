# Data Notice

This repository contains only synthetic toy data and compact derived artifacts
generated by the repository scripts from the packaged
`Tau_Core_Photon_C_DarkResidual_Package`, including:

- `scripts/run_tcdr_toys.py`;
- `scripts/run_tcdr_robustness.py`;
- `scripts/run_tcdr_blind_challenge.py`;
- `scripts/run_tcdr_realistic_mock_challenge.py`.

The repository also contains a small TCDR-v4 real-data source manifest generated
by `scripts/build_tcdr_v4_real_data_manifest.py`. The manifest lists external
public data sources and their allowed protocol roles; it does not include the
external survey data themselves.

The optional `scripts/download_tcdr_v4_sparc_endpoint.py` script downloads
compact SPARC endpoint/baseline files into `data/external/`, which is ignored
by git. Those downloaded files are local preflight inputs and are not part of
the repository release.

The committed SPARC source-freeze queue is derived from SPARC sample metadata
and intentionally excludes `Vflat` and rotation-curve endpoint values. It is a
candidate-review ledger for future external morphology lookup, not an endpoint
analysis.

The committed P0 S4G lookup artifact contains compact source-side morphology
fields for matched P0 candidates only. It is derived from the public IRSA TAP
`s4gcat` table and remains a source-freeze aid, not a rotation-curve endpoint
analysis.

The committed P0 S4G coordinate-lookup artifact uses SIMBAD name resolution
and S4G coordinates to resolve name-alias cases. It is still a source-side
morphology-availability artifact and does not inspect rotation endpoints.

The committed P0 SIMBAD fallback artifact records catalogue identity and
morphological-type fields for non-S4G P0 objects. It is a weaker fallback
source ledger, not a homogeneous morphology catalogue and not endpoint
evidence.

The committed P0 source-tier manifest combines S4G and SIMBAD source ledgers
into a freeze-ready source-quality hierarchy. The tiers describe source
availability only and must not be read as endpoint performance classes.

The committed P0 source-family freeze maps source-side morphology tiers to
candidate readout families. These family labels are allowed pre-endpoint
hypotheses only; they are not fit results and do not use rotation residuals.

The committed P0 pilot holdout manifest is derived only from the committed
source-family freeze artifact. It selects a small, endpoint-blind,
family-balanced homogeneous-S4G pilot subset for later scoring work. It is not
a fit table, does not inspect rotation endpoints, and does not claim that the
selected family will improve any galaxy.

The pilot split is calibration aware. It leaves train support in each selected
homogeneous family and the optional local scoring script blocks families with
fewer than two train galaxies from acting as calibrated matched or wrong-family
controls. This prevents a one-object family amplitude from being promoted into
an endpoint result.

The committed P0 holdout endpoint-readiness manifest records only availability
and coarse count/radial metadata for the frozen holdout objects. The actual
SPARC endpoint curve packet is written locally under `data/external/` and is
not committed. The readiness manifest is not an endpoint score, baseline
comparison, or observational claim.

The committed P0 source-native kernel-coordinate audit is also endpoint-blind.
It records that the present family labels are source proxies: barred and ring
families require structural decomposition, exponential disks have only partial
disk/H I proxy coordinates, diffuse late disks need more train support, and
identity-only cases are not kernel-freeze ready. This audit may guide future
source acquisition but must not be read as endpoint scoring.

The committed P0 bar/ring decomposition source-route artifact is endpoint-blind
as well. It queries the machine-readable S4G Pipeline 4 decomposition catalogue
(`J/ApJS/219/4`) and S4G feature catalogue (`J/A+A/582/A86`) through VizieR and
records only source-side structural-coordinate availability. It does not read
SPARC rotation curves, residuals, endpoint scores, or wrong-family margins. Its
role is to identify which P0 barred/ring/spiral objects already have public
bar length, ring radius, or pitch-angle coordinates that could support a later
frozen kernel rule.

The committed P0 source-native kernel-coordinate freeze is endpoint-blind. It
uses only the source-route artifact plus source-side SPARC sample metadata to
convert available S4G bar/ring angular radii into physical kernel coordinates.
It does not read endpoint curves, residuals, wrong-family scores, or fitted
improvement margins. Uncovered objects remain explicit source-proxy fallbacks.

The committed P0 source-native component-mixture audit is endpoint-blind. It
uses the same S4G source-route and coordinate-freeze artifacts to record
whether source-native bar, ring, and spiral-pitch components coexist in a
galaxy. It does not score curves. Its role is to distinguish pure wrong-family
controls from source-visible secondary/mixed components.

The committed P0 source-native mixed-component kernel freeze is also
endpoint-blind. It converts the component-mixture audit into a fixed component
weight rule before endpoint scoring. It does not inspect endpoint curves,
residuals, fitted amplitudes, wrong-family scores, or validation outcomes.

The optional holdout endpoint-scoring preflight writes its results only under
`data/external/`. Those local outputs are diagnostic and are not part of the
released source package. They must not be cited as population validation or as
evidence for a physical dark residual without a separate frozen endpoint
protocol and public-result promotion step. The current author-local scoring
pass uses train-pool-only specificity-first v4 kernels. It improves the frozen
baryonic carrier on all scoreable holdout objects, but it does not yet
systematically beat calibrated wrong-family controls; this is recorded as a
kernel-development diagnostic rather than an endpoint result.

The optional kernel-specificity diagnosis also writes only under
`data/external/`. It is allowed to inspect the already frozen local scoring
outputs to decide what source-native morphology coordinate is missing next,
but it is not allowed to change the frozen holdout labels or promote a
matched-family score to validation. Its current role is to document whether
wrong-family wins are generic or structured; the present local diagnosis points
to exponential-disk leakage into barred/ring cases, not to a validated endpoint
readout.

The optional source-native coordinate scoring replay also writes only under
`data/external/`. It tests the frozen coordinate rule against the same local
holdout endpoint packet. Its current role is diagnostic: source-native
bar/ring coordinates improve some matched objects and the median
matched-minus-baryonic-carrier margin, but they do not yet systematically beat
calibrated wrong-family controls.

The optional mixed-component scoring replay also writes only under
`data/external/`. It tests one source-frozen mixed-component model against the
same local holdout packet. Its current role is diagnostic: it improves several
pure matched-family cases but still does not systematically beat calibrated
wrong-family controls.

No real endpoint curve packets, lensing maps, cosmological likelihood products,
or population-validation survey products are included. The committed source
manifests do include compact source-side catalogue metadata needed to
reproduce the endpoint-blind morphology and kernel-coordinate ledgers. The
numerical results are methodology checks, not observational evidence.
